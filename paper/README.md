# Manuscript

LaTeX source of the paper submitted to the *IEEE Sensors Journal*. It uses the
official IEEE JSEN template: `ieeecolor.cls`, `jsen.sty` and `IEEEtran.bst`
are unmodified copies from `IEEE-JSEN-LaTeX-template-202405.zip`.

```sh
python experiments/e6/analyse.py results/e6_20261110   # statistics and E6 summaries
python experiments/e7_summary.py                        # E7 summary
python paper/make_assets.py                             # all tables and figures, ram.json
cd paper && latexmk -pdf main.tex
```

- `main.tex`: text; `references.tex`: bibliography.
- `tables/`, `figures/`: generated by `make_assets.py` from the committed results.
- `ram.json`: RAM accounting of every configuration (Table VIII).
