# enose-drift-mcu

Code, protocol, results and firmware for the paper

> O. Kuznetsov, "Memory and Time Costs of Drift Compensation and Calibration
> Transfer for Electronic Noses on Microcontrollers", submitted to the
> *IEEE Sensors Journal* (special issue "Bio-Inspired Multi-modal Sensors:
> Electronic Nose, Tongue, and Skin").

The study measures the accuracy, the RAM and the execution time of linear
drift-compensation and calibration-transfer methods for metal-oxide gas sensor
arrays, on two public UCI datasets and on Arduino Mega2560, ESP32-C3 and
ESP32-S3 boards. The manuscript source is in [`paper/`](paper/).

## Requirements

Python 3.10 or newer and the packages in `requirements.txt`. The float32 C
replica (E6) needs `gcc` on the host; the board runs need PlatformIO and
pyserial (`mcu/requirements.txt`). Building the paper needs a TeX
distribution with `latexmk`.

```bash
pip install -r requirements.txt
python scripts/download_data.py      # about 225 MB from archive.ics.uci.edu, SHA-256 verified
python scripts/extract_d2.py         # D2 features -> data/cache/d2_features.npz
python -m pytest -q
```

`scripts/download_data.py --from DIR` uses zip files that are already on disk
(they are still verified).

## Reproducing the results

Each runner writes into the output folder given as its first argument; the
committed results were produced with the defaults (20 seeds).

| Step | Command | Committed output |
| --- | --- | --- |
| E1, E2 (drift, D1) | `python experiments/e1e2/run.py results/e1e2_20261109` | `results/e1e2_20261109` |
| E3 (concentration) | `python experiments/e3/run.py results/e3_20261109` | `results/e3_20261109` |
| E4 (transfer, D2) | `python experiments/e4/run.py results/e4_20261109` | `results/e4_20261109` |
| E5 (boards, fixture) | see [`mcu/README.md`](mcu/README.md); `python experiments/e5/analyse.py results/e5_20261109` | `results/e5_20261109` |
| E6 (post hoc, host) | `python experiments/e6/run_d1.py results/e6_20261110`, `run_d2.py`, `run_d2_conc.py`, `ext_full.py`, `day_matrix.py` (same folder), then `python experiments/e6/analyse.py results/e6_20261110` | `results/e6_20261110` |
| E7 (boards, complete streams) | see [`mcu/README.md`](mcu/README.md); `python experiments/e7_summary.py` | `results/e7_20261110` |
| Tables and figures | `python paper/make_assets.py` | `paper/tables`, `paper/figures` |
| Manuscript | `cd paper && latexmk -pdf main.tex` | `paper/main.pdf` |

Recorded run times with `--jobs 4` (`run_info.json`): E1/E2 12 min, E3
45 min, E4 2 min. `paper/make_assets.py` only reads the committed
results and refits nothing.

## Relation to other work

The online-update code (NLMS, RLS, block least squares) and the MCU timing
harness are adapted from the author's earlier repository
[lut-kan-native](https://github.com/KuznetsovKarazin/lut-kan-native) (MIT).
No data or results are shared with it.
